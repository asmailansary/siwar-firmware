# نظام السوار الوطني (Firmware)

النظام الذي يعمل داخل **السوار الوطني**: يستقبل الإنذار الوطني من شبكة الجوال، ويُنبّه لابسه بالاهتزاز والضوء، ويرسل «أنا بأمان» إلى أساور أهله بدون إنترنت.

فكرة وابتكار: **إسماعيل النجار الأنصاري**. جميع الحقوق محفوظة. مستودع خاص.

## يعمل الآن على

لوحة التطوير **Nordic Thingy:91 X** (نفس شريحة السوار nRF9151). عند وصول السوار الحقيقي يُضاف له ملف لوحة خاص، ويبقى باقي النظام كما هو.

## أجزاء النظام

| الملف | وظيفته |
|---|---|
| `src/state.c` | عقل السوار: يقرر ماذا يحدث عند الإنذار والأزرار وزوال الخطر |
| `src/ui.c` | الأزرار والضوء والاهتزاز والصوت والشاشة |
| `src/alert.c` | استقبال الإنذار الوطني عبر البث الخلوي |
| `src/family.c` | قائمة الأهل، وإرسال واستقبال «أنا بأمان» |
| `src/main.c` | تشغيل كل الأجزاء بالترتيب |

## حالات السوار

```
مطفأ ──زر──▶ مضاء ١٠ ثوانٍ ──▶ مطفأ
أي حالة ──إنذار──▶ إنذار (اهتزاز + برتقالي)
إنذار ──إغلاق التنبيه──▶ برتقالي بدون اهتزاز
إنذار ──أنا بأمان──▶ أخضر + إرسال لأساور الأهل
──زوال الخطر──▶ أخضر ٣ دقائق ──▶ مطفأ
```

خارج الإنذار، الأزرار تضيء الشاشة فقط ولا ترسل شيئًا.

## التجربة على لوحة التطوير

- الزر ١ = «أنا بأمان»، الزر ٢ = «إغلاق التنبيه».
- **اضغط الزرين معًا ٣ ثوانٍ** = إنذار تجريبي. وأثناء الإنذار = زوال خطر تجريبي.
- لإضافة رقم للتجربة: ضع `CONFIG_SIWAR_DEV_FAMILY_PHONE="05XXXXXXXX"` في `prj.conf`.

## البناء

يُبنى تلقائيًا في GitHub (تبويب **Actions**) مع كل تحديث، والملف الجاهز يظهر في نتيجة البناء.

على الكمبيوتر بعد تثبيت nRF Connect SDK:

```
west build -b thingy91x/nrf9151/ns
west flash
```
